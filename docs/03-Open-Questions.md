# أسئلة مفتوحة قبل بدء البرمجة

أجب بالأرقام فقط (مثال: 1-أ، 2-نعم…). أي سؤال بدون إجابة نعتمد فيه الافتراض المكتوب.

| # | السؤال | الافتراض الحالي |
|---|---|---|
| 1 | التقنية: (أ) Laravel + MySQL (ب) ASP.NET Core + SQL Server (ج) Vue + Express + MySQL | (أ) Laravel + MySQL |
| 2 | مكان التشغيل: استضافة Hostinger مشتركة، VPS، أم سيرفر محلي داخل الفندق؟ | Hostinger مشتركة + إمكانية تشغيل محلي |
| 3 | فندق واحد أم عدة فنادق (Multi-Property) من البداية؟ | فندق واحد، مع `hotel_id` جاهز للتوسع |
| 4 | عدد الغرف التقريبي؟ | حتى 200 غرفة |
| 5 | هل تُسعّر الإقامة بالليلة فقط أم يوجد أيضًا إيجار شهري/شقق فندقية؟ | بالليلة + سعر شهري اختياري |
| 6 | البلد والضريبة: نسبة الضريبة ورسوم الخدمة، وهل الفوترة الإلكترونية (JoFotara) مطلوبة؟ | الأردن: ضريبة + خدمة قابلة للإعداد، الفوترة الإلكترونية لاحقًا |
| 7 | هل المطعم يستخدم نظام POS2026 الحالي (ربط API) أم شاشة Outlet داخل نظام الفندق؟ | شاشة Outlet داخلية أولًا، والربط لاحقًا |
| 8 | هل نحتاج ربط مع Booking.com / Expedia (Channel Manager)؟ | لا في الإصدار الأول |
| 9 | هل نسمح بالـOverbooking؟ | لا، إلا بصلاحية مدير على مستوى نوع الغرفة |
| 10 | Check-Out: هل يجب أن يكون الرصيد صفرًا دائمًا، أم نسمح بتحويله لحساب شركة (City Ledger)؟ | صفر أو City Ledger بموافقة |
| 11 | وقت Night Audit: يدوي من المدقق أم تلقائي في ساعة محددة؟ | يدوي مع تذكير |
| 12 | هل تحتاج تطبيق جوال للتدبير الفندقي (تحديث حالة الغرف من الجوال)؟ | واجهة ويب متجاوبة (PWA) |
| 13 | اسم الفندق والشعار للطباعة والفواتير؟ | اسم تجريبي |
